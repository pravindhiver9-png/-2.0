# Hamari Chit Fund Demo — Homepage

This is a GitHub-ready Android project containing the homepage preview.

## Build APK on GitHub
1. Upload the contents of this folder to your `Hamari-Chit-Fund-Demo` repository (keep the folder structure).
2. Open the repository's **Actions** tab.
3. Select **Build Android APK** and tap **Run workflow** (or let it build after pushing to `main`).
4. Open the completed workflow run and download the `hamari-chit-fund-homepage-apk` artifact.

## Important
The current screen intentionally displays the supplied reference image edge-to-edge. This preserves the exact screenshot appearance. It is a visual homepage prototype: the cards, shortcuts and bottom navigation are not functional yet. They can be rebuilt as real Android controls in the next stage.
